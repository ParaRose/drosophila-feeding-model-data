# Cross-connectome transfer of a Drosophila spiking feeding model: proofreading stability, reconstruction shifts, and homolog calibration

Supporting dataset and MIT-licensed code for the V7 manuscript by Zihao Peng and Zhuoye Li (release `v7.0`; releases `v5.0` and `v6.0` are retained for provenance). Files in `data/` match the submission supplements. `S1_Text.pdf` describes the protocols and expanded disinhibition details; `S1_Fig.tif` and `S1_Table`–`S7_Table` report the supporting results; `docs/MN9_PORTABILITY_PROTOCOL_zh.md` archives the original Chinese-language analysis protocol (timestamped 2026-11-24 10:51:58 +0800).

| Machine-readable file | Contents |
| --- | --- |
| `data/S1_Table.tsv` | Behavioral labels, mapped counts, dimorphism tags (`unmapped` for unmapped MaleCNS types `vice`/`weaver`), and simulated MN9 responses by cell type and connectome |
| `data/S3_Table.tsv` | Rewired graph controls and left/right MN9 readouts |
| `data/S5_Table.tsv` | Candidate-specific local stimulation tests (bilateral mean and MaleCNS intact left MN9) |
| `data/S7_Table.tsv` | Cross-connectome motif comparisons and shared intermediates |

The input connectomes are distributed by their original providers: [FlyWire](https://codex.flywire.ai/), [BANC v888](https://doi.org/10.7910/DVN/7WTH1N), and [MaleCNS](https://neuprint.janelia.org/). The present snapshot contains study outputs, scripts, and manifests. `SHA256SUMS` lists SHA-256 checksums for every archived file (`data/`, `results/`, `code/`, and `docs/`).

## Simulation results

The `results/` directory contains the nine study result JSON files covering the FlyWire v630/v783, BANC v888, and MaleCNS v1.0 primary benchmarks, portability hardening, disinhibition scans, pre-submission calibration experiments, and V5–V7 reviewer controls.

## Reproduce the published figures, TSV tables, and S2A/V7 verification

From the repository root, run the following commands in a Python 3.11+ environment (requires no raw connectome downloads):

```sh
python -m pip install numpy==1.26.4 scipy==1.11.4 matplotlib==3.8.0
python -c "from pathlib import Path; import shutil; d=Path('reproduce-v7'); d.mkdir(exist_ok=True); [shutil.copy2(p,d) for p in [*Path('code').glob('*.py'),*Path('code').glob('*.json'),*Path('results').glob('*.json')]]"
PYTHONHASHSEED=0 python reproduce-v7/english_figures.py
python code/verify_s2a_from_archived_jsons.py
```

The generated `supp_table1`, `supp_table2`, `supp_table3`, and `supp_table4` correspond respectively to `data/S1_Table.tsv`, `data/S5_Table.tsv`, `data/S7_Table.tsv`, and `data/S3_Table.tsv` (verified byte-identical).

## Run simulations from connectome inputs

The simulation scripts in `code/` correspond to the FlyWire v630 benchmark (`shiu_mn9_benchmark.py`), v783 transfer (`mn9_transfer_benchmark.py`), BANC (`mn9_banc_benchmark.py`), MaleCNS (`mn9_malecns_benchmark.py`, using bundled `mn9_malecns_input_manifest.json`), background-state/disinhibition scans (`mn9_disinhibition_state.py`, GPU version `mn9_disinhibition_colab_gpu.py`), and follow-up controls (`mn9_portability_hardening.py`, `mn9_pre_submission_ab.py`, `mn9_v5_reviewer_controls.py`, `mn9_v7_final_controls.py`). Local CPU stages read `PROJC_CACHE_DIR`; cloud GPU stages read `RESEARCH_CACHE_DIR`. Raw connectomes are not bundled; place the publicly downloaded source files under `$PROJC_CACHE_DIR` with the following layout:
